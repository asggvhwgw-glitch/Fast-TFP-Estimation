# Fast TFP Estimation

High-performance Python implementation of structural production function estimators:

- Olley-Pakes (OP)
- Levinsohn-Petrin (LP)
- Ackerberg-Caves-Frazer (ACF)
- Gandhi-Navarro-Rivers (GNR)

Theory-first implementation targeting large-scale firm-panel estimation.

Status: v0.4.0 theory-first release candidate.
